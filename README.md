# كيمياء الخامس العلمي

شرح تفاعلي لفصول كتاب الكيمياء للصف الخامس العلمي الثمانية: مجسمات ثلاثية الأبعاد، مختبر تفاعلي، التعاريف والمسائل المهمة وحلها، وتحدّي الفرق.

- **الموقع:** https://zraij.github.io/chem5/ (يحتاج تسجيل دخول)
- **إدارة الحسابات:** https://zraij.github.io/chem5/admin.html (لصاحب الموقع فقط)
- **لوحة إدارة موحّدة:** نفس `admin.html` موجود بكل الكتب ويدير كل الكتب من مكان واحد (أزرار للتبديل بين الكتب). أي تعديل عليه لازم ينسخ لكل المستودعات.
- **الاشتراكات:** كل حساب (عدا المدير) له تاريخ انتهاء `e` بـ `users.json` (`pm` = عدد الأشهر، `tr` = أيام التجربة). الحسابات القديمة بدون تاريخ تنتهي `2026-12-01` (من 1 تشرين الثاني لمدة شهر). عند الانتهاء تظهر شاشة التجديد برقم 07746451098.
- **تنبيه للمطوّر:** كود الاشتراك (`subFetch` / `subExpired` / `subBadge`) مضاف بالجزء غير المشفّر من `index.html`؛ بعد أي إعادة بناء تأكد أنه موجود.

محتوى الصفحة مشفّر، ولا يُفتح إلا بحساب صحيح. الحسابات محفوظة في `users.json` بشكل مشفّر، وتُدار من صفحة الإدارة. كل حساب أستاذ يُقفل على أول جهاز يدخل منه، وحساب المدير مستثنى من القفل.

- **رابط التثبيت (يُرسل للأساتذة):** https://zraij.github.io/chem5/install.html — يثبّت البرنامج كتطبيق على الموبايل والشاشات التفاعلية
- **حساب الشاشة التفاعلية:** من صفحة الإدارة ← «إضافة شاشة تفاعلية»، حساب لكل شاشة حتى ما تنقفل حسابات الأساتذة عليها
- **تنبيه للمطوّر:** بعد أي إعادة بناء لـ `index.html` تأكد أن سطر `manifest.webmanifest` وكود `__PWA` بعده موجودان، وإلا يختفي التثبيت كتطبيق
